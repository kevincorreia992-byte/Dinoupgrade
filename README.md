# DinoCard

**Projeto de jogo desenvolvido em Python com Pygame — 2026**

## Objetivo

O **DinoCard** é um jogo de dinossauro que combina progressão por pontuação, desafios em diferentes biomas e um sistema de cartas com habilidades e melhorias. O objetivo é avançar pelas fases, superar os desafios e enfrentar os chefes (*bosses*) durante a jornada.

## Funcionalidades

- Menu inicial do jogo.
- Diferentes biomas, incluindo floresta, deserto e neve.
- Progressão por pontuação e enfrentamento de bosses.
- Sistema de cartas com habilidades e melhorias.
- Sistema de habilidades.
- Cosméticos e opções de personalização.
- Menu de configurações.
- Músicas e efeitos sonoros.

> **Status:** projeto em desenvolvimento. Algumas funcionalidades podem ser ajustadas até a versão final.

## Tecnologias utilizadas

- Python 3
- Pygame
- Visual Studio Code

## Como executar

### Pré-requisitos

- Computador com Python 3 instalado.
- Biblioteca Pygame instalada.

O jogo foi testado no **Windows 10/11**.

### Passo a passo

1. Baixe o projeto pelo GitHub, usando **Code > Download ZIP**, e extraia a pasta (ou clone o repositório com Git).
2. Abra o terminal na pasta principal do projeto, onde está o arquivo `main.py`.
3. Instale as dependências:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Inicie o jogo:

   ```bash
   python main.py
   ```

> No Windows, caso o comando `python` não seja reconhecido, tente `py` no lugar de `python`.
>
> Mantenha as pastas de imagens, sprites, músicas e demais recursos junto ao projeto, preservando sua estrutura original.
